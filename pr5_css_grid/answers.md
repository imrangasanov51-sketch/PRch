# Ответы ПР5

1. display: grid включает Grid. Grid двумерный, Flexbox одномерный.
2. grid-template-columns — явные колонки, grid-auto-columns — неявные.
3. repeat() — повторы, minmax() — диапазон, auto-fit — растягивает.
4. grid-template-areas — именованные области.
5. Линии с 1; grid-column: 1 / 3 — от 1-й до 3-й.
6. gap лучше margin — без побочных эффектов.
7. justify-items — по горизонтали, align-items — по вертикали.
8. auto-fill оставляет пустые треки, auto-fit растягивает.
9. Имена областей в кавычках, точки — пустые.
10. Grid двумерный, поддерживает шаблоны, адаптивность.
