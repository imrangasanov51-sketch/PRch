# Ответы ПР3

1. Класс: 0,1,0, повторяемый. ID: 1,0,0, уникальный.
2. Каскад: важность > специфичность > порядок.
3. ul li.important = 0,1,2; #site-title = 1,0,0; .content > .featured-post = 0,2,0.
4. Наследуются: color, font-family, font-size. Не наследуются: margin, padding, border.
5. > — прямые дети; пробел — все потомки.
6. :hover — интерактивность, :nth-child() — чётные/нечётные.
7. !important переопределяет всё — использовать осторожно.
8. ::before/::after добавляют контент через content.
9. При равной специфичности — ниже в CSS побеждает.
10. DevTools показывают применённые стили и порядок.
