# Ответы на вопросы ПР1

1. Три области Git: рабочая папка (черновики), индекс (staging, после add), репозиторий (.git, история коммитов).
2. git add — в индекс, git commit — фиксирует, git push — отправляет на удалённый.
3. Информативные сообщения объясняют что и зачем. Ускоряют ревью и откат.
4. git add file — конкретный файл; git add . — всё. Точечно — для разделения коммитов.
5. git status показывает состояние рабочей папки и индекса.
6. git remote add origin URL — связь с удалённым. origin — стандартное имя.
7. Флаг -u связывает локальную и удалённую ветку, далее можно без аргументов.
8. По умолчанию main (раньше master). Важно для совместимости с GitHub.
9. git log — история: хеш, автор, дата, сообщение.
10. Без git add изменения не попадут в коммит.
