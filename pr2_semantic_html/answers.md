# Ответы ПР2

1. Семантическая использует теги по смыслу, несемантическая — div/span. Важна для SEO, доступности.
2. article — самостоятельный блок; section — тематическая секция.
3. header и footer могут использоваться несколько раз (body, article, section).
4. main — уникальный контент страницы, div не несёт семантики.
5. nav — блок навигации. Обязателен для меню, хлебных крошек.
6. datetime — машиночитаемый формат, важен для SEO.
7. figure/figcaption — связь изображения с подписью.
8. aside — боковой контент, косвенно связанный с основным.
9. Помогает поисковикам и скринридерам понимать структуру.
10. Использованы: header, nav, main, article, section, aside, footer, figure, figcaption, time, details, summary, address.
