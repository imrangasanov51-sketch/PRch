# Ответы ПР10

1. Declaration поднимается (hoisting), Expression — нет.
2. Rest — массив; arguments — псевдомассив, только в обычных функциях.
3. Замыкание — доступ к переменным лексического окружения.
4. Рекурсия короче; итерация быстрее без переполнения стека.
5. map, filter, reduce — функции высшего порядка.
6. Каррирование — f(a,b,c) → f(a)(b)(c).
7. Мемоизация — кэш результатов чистых функций.
8. Debounce — вызов после паузы; Throttle — не чаще интервала.
9. Генераторы function*, yield, возвращают итератор.
10. Чистые функции, иммутабельность, композиция.
