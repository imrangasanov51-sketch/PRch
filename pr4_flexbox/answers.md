# Ответы ПР4

1. display: flex включает Flexbox; дети становятся flex-элементами.
2. justify-content — по главной оси, align-items — по поперечной.
3. flex-direction: row, column, row-reverse, column-reverse.
4. flex: 1 = flex-grow:1, flex-shrink:1, flex-basis:0%.
5. flex-wrap — перенос на новую строку.
6. align-content — выравнивание строк, align-items — элементов в строке.
7. order — меняет порядок отображения без DOM.
8. Main axis и cross axis зависят от flex-direction.
9. Адаптивность без медиа: flex-wrap: wrap + flex: 1 1 200px.
10. gap задаёт промежутки без margin.
