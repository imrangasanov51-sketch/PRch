# Ответы на вопросы для самоконтроля — ПР18

1. **Link vs NavLink**: оба делают клиентский переход без перезагрузки страницы. NavLink дополнительно добавляет класс/стиль активному маршруту (prop className={({isActive}) => ...} или activeClassName в v5). NavLink — для навигационных меню, Link — для обычных ссылок.

2. **Параметры URL**: хук useParams() возвращает объект с параметрами динамического сегмента: <Route path="/products/:id" /> + const { id } = useParams(). Также useSearchParams() для query-строк (?page=2), useLocation().search + URLSearchParams.

3. **Программная навигация**: переход без клика по ссылке — через хук useNavigate(): navigate('/path'), navigate(-1) (назад), navigate('/path', { state: {...} }) (с состоянием). Вызывается в обработчиках событий, после успешной отправки формы и т.д.

4. **Передача данных между маршрутами**: (а) через location.state при navigate/Link — данные не видны в URL, доступ через useLocation().state; (б) через URL-параметры — видны, доступ через useParams; (в) через query-параметры — useSearchParams; (г) через глобальное хранилище/контекст.

5. **Routes**: контейнер, который выбирает первый подходящий Route по текущему URL (в v6 заменил Switch). Каждый Route сопоставляет path с element. Работает как «switch»: рендерится только один совпавший маршрут.

6. **Защищённый маршрут**: компонент-обёртка, проверяющий условие (например, наличие токена авторизации) и либо рендерящий <Outlet/> (дочерние маршруты), либо перенаправляющий на /login через <Navigate to="/login" />. Пример: {auth ? <Outlet/> : <Navigate to="/login" />}.

7. **useNavigate vs redirect**: useNavigate — хук для программной навигации внутри компонентов/обработчиков (реактивный). redirect() — функция из react-router-dom, возвращающая объект ответа, используется в loaders/actions (data API) и для серверных редиректов; в компонентах для редиректа при рендере используют <Navigate/>. redirect не требует контекста компонента.
