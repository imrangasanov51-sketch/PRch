# Ответы ПР6

1. Viewport meta — ширина страницы = ширина устройства.
2. Fluid, Adaptive, Responsive — комбинация.
3. Mobile First — сначала мобильные, лёгкость и производительность.
4. Единицы: %, rem, em, vw/vh — относительные.
5. clamp() — задаёт min, предпочтительное, max.
6. Брейкпоинты: 480, 768, 1024, 1200px.
7. @media применяет стили по условиям.
8. max-width — «до», min-width — «от».
9. max-width: 100%; height: auto.
10. DevTools — режим адаптивного дизайна.
