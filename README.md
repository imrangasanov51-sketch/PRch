# PRch — Практические работы

Репозиторий с практическими работами по веб-разработке.

## Структура

| Папка | Практическая работа |
|---|---|
| `pr1_git` ... `pr12_events` | ПР1–ПР12 (из предыдущих работ) |
| `async_operations` | ПР13: JavaScript — асинхронные операции |
| `fetch_api` | ПР14: Работа с Fetch API |
| `react_components` | ПР15: React — создание компонентов |
| `react_hooks` | ПР16: React — использование хуков |
| `react_forms` | ПР17: React — работа с формами |
| `react_routing` | ПР18: React — маршрутизация |

## Запуск

- **ПР13, ПР14**: открыть `index.html` в браузере (или Live Server в VS Code).
- **ПР15–ПР18**: `npm install` затем `npm start` в соответствующей папке.

В каждой папке есть файл `answers.md` с ответами на вопросы для самоконтроля.
