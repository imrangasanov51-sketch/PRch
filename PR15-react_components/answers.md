# Ответы на вопросы для самоконтроля — ПР15

1. **Функциональные vs классовые компоненты**: функциональные — проще, с хуками покрывают всё, что и классовые; классовые — устаревший подход, громоздкий, но иногда встречается в легаси. Современный React — функциональные с хуками.

2. **Props vs state**: props — входные данные от родителя, неизменяемые внутри компонента (read-only); state — внутреннее состояние компонента, изменяется через setState/useState. Правила: не мутировать props, state обновлять только через setter, state поднимать к общему предку.

3. **Lifting state up**: когда нескольким компонентам нужно одно состояние — поднимаем его к ближайшему общему предку и передаём вниз через props. Необходимо при синхронизации данных между соседними компонентами.

4. **Методы жизненного цикла**: constructor (инициализация state), render (рендер), componentDidMount (после монтирования: подписки, запросы), componentDidUpdate (после обновления props/state), componentWillUnmount (перед удалением: очистка подписок, таймеров), shouldComponentUpdate (оптимизация рендеров), getDerivedStateFromProps (редкий).

5. **useState и useEffect**: useState — [value, setter] для локального состояния. useEffect — побочные эффекты (запросы, подписки, таймеры); массив зависимостей: [] — один раз при монтировании, [dep] — при изменении dep, нет массива — каждый рендер. Правила хуков: только на верхнем уровне, только в React-функциях.

6. **Keys**: уникальные идентификаторы элементов списка, помогают React определить, какие элементы изменились/добавились/удалились. Без keys React перерисует весь список — потеря фокуса, анимаций, состояния. Ключ = стабильный id, не индекс массива.

7. **События в React**: camelCase (onClick, onChange), передаём функцию-обработчик, синтетические события (SyntheticEvent) — кроссбраузерная обёртка, нельзя вызвать async напрямую в JSX — оборачивать. Отличие от нативного: делегирование, пул событий (в 17+ нет пула), preventDefault вместо return false.

8. **Управляемые vs неуправляемые**: управляемые — значение из state, onChange обновляет state (React контролирует); неуправляемые — значение в DOM, читаем через ref. Управляемые — предпочтительны (валидация, форматирование); неуправляемые — для файлов, интеграции с jQuery-плагинами.

9. **Context**: механизм передачи данных через дерево без пропс-дриллинга (createContext + Provider + useContext). Использовать для глобальных данных: тема, язык, авторизация. Не заменяет state management для сложной логики.

10. **Кастомные хуки**: функции, начинающиеся с use, которые используют другие хуки. Извлекают логику в переиспользуемые модули (useLocalStorage, useFetch). Лучшие практики: один хук — одна задача, возвращать объект/массив, называть с use, соблюдать правила хуков.
