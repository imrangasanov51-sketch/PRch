# Ответы ПР11

1. innerHTML парсит HTML; textContent — только текст, безопаснее.
2. Делегирование — один обработчик на родителе.
3. getElementById, querySelector, querySelectorAll.
4. preventDefault отменяет стандартное поведение.
5. classList.add() безопаснее className.
6. createElement + appendChild. Альтернатива — insertAdjacentHTML.
7. Всплытие — от target вверх. stopPropagation останавливает.
8. FormData, form.elements, value.
9. input — при каждом изменении; change — при blur; keyup — при отпускании.
10. DocumentFragment, batch-изменения, debounce.
